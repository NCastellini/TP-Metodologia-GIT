# `git log`
Muestra el historial de commits del repositorio. 

```
git log                   # historial completo
git log --oneline         # una línea por commit   
```

## Ejemplo en nuestro repositorio

### `git log`
```
commit 46258002ec08817c0d9f7e8bda554722938d2eda
Author: Sanger <sangeralejo7@gmail.com>
Date:   Mon Jun 1 17:49:51 2026 -0300

    docs: agrega explicación de git pull
```

### git `git log --oneline`
```
554f1ca (HEAD -> alumno_sanger, origin/alumno_sanger) docs: corrige explicacion de git pull
4625800 docs: agrega explicación de git pull
55b432c docs: agrega explicación de git push
```
