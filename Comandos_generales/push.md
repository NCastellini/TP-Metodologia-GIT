# `git push`

Sube los commits locales al repositorio remoto. Es el comando que "sincroniza" los cambios de tu repositorio local con el repositorio remoto (por ejemplo, GitHub).
 
Sintaxis:
```
git push origin <nombre-rama>
```

## Ejemplo
```
git push origin main
```
Esto significa:
* `push` -> enviar cambios 
* `origin` -> al remoto llamado "origin"
* `main` -> la rama a subir
