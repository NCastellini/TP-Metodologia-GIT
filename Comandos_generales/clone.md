# git clone

## ¿Qué es?

El comando `git clone` se utiliza para copiar un repositorio remoto a nuestra computadora. Al clonarlo obtenemos todos los archivos, ramas e historial de commits del proyecto.

## Sintaxis

```bash
git clone <url-del-repositorio>
```

## Ejemplo

Para descargar el repositorio del trabajo práctico desde GitHub:

```bash
git clone https://github.com/usuario/trabajo-practico-git.git
```
