# `git pull`

Trae los cambios del repositorio remoto y los integra en tu rama local, manteniendo tu copia del proyecto actualizada.

Sintaxis:
```
git pull origin <nombre-rama>
```
  
Ejemplo:
```
git pull origin main
```
  
Esto siginifica:
* pull -> obtener y agregar los cambios del repositorio remoto.
* origin -> el repositorio remoto del que se descargan los cambios.
* main -> la rama de la que se obtienen los cambios.
