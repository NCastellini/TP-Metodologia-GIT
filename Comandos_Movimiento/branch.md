# git branch

## ¿Qué es?

El comando `git branch` se utiliza para crear, listar, renombrar y eliminar ramas dentro de un repositorio Git. Las ramas permiten desarrollar nuevas funcionalidades o realizar modificaciones sin afectar el trabajo principal.

## Sintaxis

```bash
git branch
```

Muestra todas las ramas locales existentes en el repositorio.

Visualizar las ramas disponibles:

```bash
git branch
```

Salida de ejemplo:

```text
* main
  dev
  NCastellini
```

---


```bash
git branch nombre-rama
```

Crea una nueva rama.

## Ejemplo

Crear una rama llamada `NCastellini`:

```bash
git branch NCastellini
```

## Ejemplo

```bash
git branch nueva-rama
```

Permite crear una nueva rama local.
